Coaching toolkit · 5-1 system

Plan the rotation, call the set, read the numbers.

Three browser tools for a volleyball team: a rotation playbook and stat tracker, a setter's signal and set map, and a serve-receive reference. They run on a phone courtside and need no account or backend.

Under the hood

Every stat, whether entered live, from video, or simulated, lands in one flat event log. Everything the app reports is computed from that log.

Event pipeline

Rallies flatten into touch events, which are aggregated by player, rotation, match and set.

Ratings from data

Each rating starts from a baseline and moves toward what the stats show, weighted by sample size.

Data-quality tests

CI checks that scores reconcile, every event references a real player and rally, and roll-ups lose nothing.

Seeded demo season

A rally simulator plays 7 matches (about 900 rallies) so every screen has data from the first visit.
